## 2. Modal Lấy Lẻ Thùng Gốc & Tạo Thùng Ảo (SCR-PICK-02 / UC17)

When user clicks `[ 📦 LẤY LẺ TỪ THÙNG GỐC / THÙNG ẢO (UC17) ]`:

```text
+-----------------------------------------------------------------------------------+
|  📦 TÁCH LẺ TỪ THÙNG GỐC & TẠO THÙNG ẢO (UC17)                          [ X ]      |
+-----------------------------------------------------------------------------------+
|  Mặt Hàng: D.555                                                                  |
|                                                                                   |
|  1. Chọn Thùng 60 Gốc Khả Dụng Trong Kho:                                         |
|  +-----------------------------------------------------------------------------+  |
|  | Chọn Thùng Gốc: [ K07/1/D.555/MT/L3/11/151 - Vị trí: C41/2 - Tồn: 60 SP ▼ ]   |  |
|  +-----------------------------------------------------------------------------+  |
|                                                                                   |
|  2. Nhập Số Lượng Cần Lấy Lẻ:                                                     |
|  [ 3                                                                        ] SP  |
|                                                                                   |
|  ⚠️ Hệ thống sẽ tự động:                                                          |
|  - Trừ số lượng tồn thùng gốc (60 -> 57 SP) & chuyển sang BLOCKED.               |
|  - Sinh Thùng Ảo mới (Qty = 3 SP, is_virtual = 1) và tự động quét vào Phiếu Xuất.|
|                                                                                   |
|                                       [ Hủy Bỏ ]   [ ✅ XÁC NHẬN TÁCH & QUÉT ]    |
+-----------------------------------------------------------------------------------+
```
