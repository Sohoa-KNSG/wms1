# UC02 - Nhận dữ liệu phiếu giao kho từ sản xuất

## 1. Mục tiêu nghiệp vụ

Use Case này dùng để nhân viên kho tiếp nhận dữ liệu phiếu giao kho từ sản xuất, kiểm tra thông tin phiếu, cập nhật mã đơn hàng nếu cần, sau đó thực hiện quét nhập kho thành phẩm.

Dữ liệu phiếu nhập được lấy từ ERP thông qua view phiếu nhập kho thành phẩm. Mã đơn hàng được lấy từ dữ liệu đơn hàng OEM và được nhân viên kho cập nhật trước khi bắt đầu quét nhập.

---

## 2. Tác nhân chính

| Tác nhân | Vai trò |
|---|---|
| Nhân viên kho | Chọn phiếu giao kho, kiểm tra chi tiết, cập nhật mã đơn hàng, thực hiện quét nhập |
| Hệ thống WMS | Hiển thị phiếu, lưu mapping mã đơn hàng, kiểm tra điều kiện nghiệp vụ |
| ERP / SQL Server | Cung cấp dữ liệu phiếu nhập kho và đơn hàng OEM |

## 4. Bảng dữ liệu WMS cần tạo

Không ghi mã đơn hàng ngược vào bảng ERP. Cần tạo bảng mapping riêng trong database WMS.

```sql
CREATE TABLE dbo.WMS_PhieuNhap_DonHang_Map
(
    ID BIGINT IDENTITY(1,1) PRIMARY KEY,

    SoPhieuNhap NVARCHAR(50) NOT NULL,
    MaChiTietPhieu NVARCHAR(50) NOT NULL,
    MaSanPham NVARCHAR(50) NOT NULL,
    MaDonHang NVARCHAR(50) NOT NULL,

    CreatedAt DATETIME NOT NULL DEFAULT GETDATE(),
    CreatedBy NVARCHAR(100) NULL,
    UpdatedAt DATETIME NULL,
    UpdatedBy NVARCHAR(100) NULL,

    IsDeleted BIT NOT NULL DEFAULT 0
);
```

Khuyến nghị tạo unique key để tránh một dòng phiếu bị gán trùng nhiều mã đơn đang hiệu lực:

```sql
CREATE UNIQUE INDEX UX_WMS_PhieuNhap_DonHang_Map_Active
ON dbo.WMS_PhieuNhap_DonHang_Map
(
    SoPhieuNhap,
    MaChiTietPhieu
)
WHERE IsDeleted = 0;
```

## 5. Luồng xử lý chính

### Bước 1: Nhân viên kho mở màn hình nhận phiếu giao kho

Hệ thống gọi dữ liệu từ:

```sql
SELECT *
FROM dbo.vw_WMS_PhieuNhapKhoTP_Tong
ORDER BY NgayNhap DESC, SoPhieuNhap DESC;
```

Màn hình hiển thị danh sách phiếu nhập kho.

| Thông tin | Ghi chú |
|---|---|
| Số phiếu nhập | `SoPhieuNhap` |
| Ngày nhập | `NgayNhap` |
| Đơn vị nguồn | `DonViNguon` |
| Số dòng chi tiết | `SoDongChiTiet` |
| Tổng số lượng nhập | `TongSoLuongNhap` |
| Trạng thái phiếu | `TrangThaiPhieu` |

### Bước 2: Nhân viên kho chọn một phiếu nhập

Hệ thống gọi chi tiết phiếu:

```sql
SELECT *
FROM dbo.vw_WMS_PhieuNhapKhoTP_ChiTiet
WHERE SoPhieuNhap = @SoPhieuNhap
ORDER BY MaChiTietPhieu;
```

Màn hình hiển thị danh sách mã hàng trong phiếu.

| Thông tin | Ghi chú |
|---|---|
| Mã chi tiết phiếu | `MaChiTietPhieu` |
| Mã sản phẩm | `MaSanPham` |
| Số lượng nhập | `SoLuongNhap` |
| Trạng thái release | `TenTrangThaiRelease` |
| Mã đơn hàng | Lấy từ bảng `WMS_PhieuNhap_DonHang_Map` nếu đã cập nhật |

### Bước 3: Nhân viên kho cập nhật mã đơn hàng

Trước khi quét nhập, nhân viên kho được phép cập nhật mã đơn hàng cho từng dòng chi tiết phiếu.

Khuyến nghị xử lý ở cấp dòng chi tiết, không xử lý ở cấp tổng phiếu. Lý do: một phiếu nhập có thể chứa nhiều mã hàng thuộc nhiều đơn hàng khác nhau.

Màn hình cần cho phép:

| Chức năng | Mô tả |
|---|---|
| Chọn mã đơn hàng | Lấy từ `dbo.vw_WMS_DonHangOEM_Tong` |
| Tìm mã đơn hàng | Tìm theo `MaDonHang`, `MaHang`, `MaKhachHang`, `MaPO` |
| Gán mã đơn vào dòng phiếu | Lưu vào `WMS_PhieuNhap_DonHang_Map` |
| Sửa mã đơn | Chỉ cho phép khi chưa phát sinh quét nhập |
| Xóa gán mã đơn | Chỉ cho phép khi chưa phát sinh quét nhập |

## 6. Stored Procedure khuyến nghị

### 6.1. Lấy danh sách phiếu nhập

```sql
CREATE OR ALTER PROCEDURE dbo.usp_WMS_UC02_GetDanhSachPhieuNhap
AS
BEGIN
    SET NOCOUNT ON;

    SELECT *
    FROM dbo.vw_WMS_PhieuNhapKhoTP_Tong
    ORDER BY NgayNhap DESC, SoPhieuNhap DESC;
END;
```

### 6.2. Lấy chi tiết phiếu nhập kèm mã đơn đã gán

```sql
CREATE OR ALTER PROCEDURE dbo.usp_WMS_UC02_GetChiTietPhieuNhap
    @SoPhieuNhap NVARCHAR(50)
AS
BEGIN
    SET NOCOUNT ON;

    SELECT
        ct.SoPhieuNhap,
        ct.MaChiTietPhieu,
        ct.NgayNhap,
        ct.MaSanPham,
        ct.DonViNguon,
        ct.SoLuongNhap,
        ct.TrangThaiRelease,
        ct.TenTrangThaiRelease,
        map.MaDonHang
    FROM dbo.vw_WMS_PhieuNhapKhoTP_ChiTiet ct
    LEFT JOIN dbo.WMS_PhieuNhap_DonHang_Map map
        ON ct.SoPhieuNhap = map.SoPhieuNhap
        AND ct.MaChiTietPhieu = map.MaChiTietPhieu
        AND map.IsDeleted = 0
    WHERE ct.SoPhieuNhap = @SoPhieuNhap
    ORDER BY ct.MaChiTietPhieu;
END;
```

### 6.3. Tìm kiếm đơn hàng để gán vào phiếu nhập

```sql
CREATE OR ALTER PROCEDURE dbo.usp_WMS_UC02_SearchDonHang
    @Keyword NVARCHAR(100)
AS
BEGIN
    SET NOCOUNT ON;

    SELECT DISTINCT
        MaDonHang,
        MaHang,
        MaKhachHang,
        MaPO,
        SoLuongDonHang
    FROM dbo.vw_WMS_DonHangOEM_ChiTiet
    WHERE 
        MaDonHang LIKE '%' + @Keyword + '%'
        OR MaHang LIKE '%' + @Keyword + '%'
        OR MaKhachHang LIKE '%' + @Keyword + '%'
        OR MaPO LIKE '%' + @Keyword + '%'
    ORDER BY MaDonHang, MaHang;
END;
```

### 6.4. Cập nhật mã đơn hàng cho dòng phiếu nhập

```sql
CREATE OR ALTER PROCEDURE dbo.usp_WMS_UC02_UpdateMaDonHang
    @SoPhieuNhap NVARCHAR(50),
    @MaChiTietPhieu NVARCHAR(50),
    @MaSanPham NVARCHAR(50),
    @MaDonHang NVARCHAR(50),
    @UserName NVARCHAR(100)
AS
BEGIN
    SET NOCOUNT ON;

    -- 1. Kiểm tra dòng phiếu nhập có tồn tại không
    IF NOT EXISTS (
        SELECT 1
        FROM dbo.vw_WMS_PhieuNhapKhoTP_ChiTiet
        WHERE SoPhieuNhap = @SoPhieuNhap
          AND MaChiTietPhieu = @MaChiTietPhieu
          AND MaSanPham = @MaSanPham
    )
    BEGIN
        RAISERROR(N'Dòng phiếu nhập không tồn tại.', 16, 1);
        RETURN;
    END;

    -- 2. Kiểm tra mã đơn hàng có tồn tại không
    IF NOT EXISTS (
        SELECT 1
        FROM dbo.vw_WMS_DonHangOEM_Tong
        WHERE MaDonHang = @MaDonHang
    )
    BEGIN
        RAISERROR(N'Mã đơn hàng không tồn tại.', 16, 1);
        RETURN;
    END;

    -- 3. Kiểm tra mã hàng có thuộc đơn hàng không
    IF NOT EXISTS (
        SELECT 1
        FROM dbo.vw_WMS_DonHangOEM_ChiTiet
        WHERE MaDonHang = @MaDonHang
          AND MaHang = @MaSanPham
    )
    BEGIN
        RAISERROR(N'Mã hàng không thuộc mã đơn hàng đã chọn.', 16, 1);
        RETURN;
    END;

    -- 4. Không cho sửa nếu đã phát sinh quét nhập
    -- TODO: thay bảng WMS_NhapKho_Scan bằng bảng scan thực tế của hệ thống
    IF EXISTS (
        SELECT 1
        FROM dbo.WMS_NhapKho_Scan
        WHERE SoPhieuNhap = @SoPhieuNhap
          AND MaChiTietPhieu = @MaChiTietPhieu
    )
    BEGIN
        RAISERROR(N'Dòng phiếu đã phát sinh dữ liệu quét nhập, không được sửa mã đơn hàng.', 16, 1);
        RETURN;
    END;

    -- 5. Upsert mapping mã đơn hàng
    IF EXISTS (
        SELECT 1
        FROM dbo.WMS_PhieuNhap_DonHang_Map
        WHERE SoPhieuNhap = @SoPhieuNhap
          AND MaChiTietPhieu = @MaChiTietPhieu
          AND IsDeleted = 0
    )
    BEGIN
        UPDATE dbo.WMS_PhieuNhap_DonHang_Map
        SET 
            MaSanPham = @MaSanPham,
            MaDonHang = @MaDonHang,
            UpdatedAt = GETDATE(),
            UpdatedBy = @UserName
        WHERE SoPhieuNhap = @SoPhieuNhap
          AND MaChiTietPhieu = @MaChiTietPhieu
          AND IsDeleted = 0;
    END
    ELSE
    BEGIN
        INSERT INTO dbo.WMS_PhieuNhap_DonHang_Map
        (
            SoPhieuNhap,
            MaChiTietPhieu,
            MaSanPham,
            MaDonHang,
            CreatedBy
        )
        VALUES
        (
            @SoPhieuNhap,
            @MaChiTietPhieu,
            @MaSanPham,
            @MaDonHang,
            @UserName
        );
    END;
END;
```

## 7. Business Rules

| Mã rule | Nội dung |
|---|---|
| `BR-UC02-01` | Nhân viên kho được phép cập nhật mã đơn hàng trước khi quét nhập kho. |
| `BR-UC02-02` | Mã đơn hàng phải tồn tại trong dữ liệu đơn hàng OEM. |
| `BR-UC02-03` | Mã sản phẩm trên phiếu nhập phải thuộc mã đơn hàng được chọn. |
| `BR-UC02-04` | Nên gán mã đơn hàng ở cấp dòng chi tiết phiếu nhập, không chỉ ở cấp tổng phiếu. |
| `BR-UC02-05` | Sau khi dòng phiếu đã phát sinh dữ liệu quét nhập, không cho sửa mã đơn hàng nếu người dùng không có quyền quản lý. |
| `BR-UC02-06` | Không ghi dữ liệu mã đơn hàng ngược vào bảng ERP. Chỉ lưu mapping trong database WMS. |
| `BR-UC02-07` | Một dòng chi tiết phiếu nhập chỉ được có một mã đơn hàng đang hiệu lực. |
| `BR-UC02-08` | Mã đơn hàng được gán sẽ đi theo dữ liệu thùng, pallet, vị trí lưu kho và dữ liệu xuất kho sau này. |

## 9. Điều kiện cho phép bắt đầu quét nhập

Trước khi cho phép quét nhập, hệ thống cần kiểm tra:

| Điều kiện | Cách xử lý |
|---|---|
| Phiếu nhập tồn tại | Kiểm tra trong `vw_WMS_PhieuNhapKhoTP_ChiTiet` |
| Dòng phiếu có mã đơn hàng | Kiểm tra trong `WMS_PhieuNhap_DonHang_Map` |
| Mã đơn hàng hợp lệ | Kiểm tra trong `vw_WMS_DonHangOEM_Tong` |
| Mã sản phẩm thuộc đơn hàng | Kiểm tra trong `vw_WMS_DonHangOEM_ChiTiet` |
| Dòng phiếu chưa bị khóa chỉnh sửa | Kiểm tra chưa phát sinh dữ liệu scan |

## 10. Ghi chú cho AI Developer

Khi implement UC02, cần tuân thủ hướng sau:

1. App không xử lý logic nghiệp vụ phức tạp.
2. App chỉ gọi Stored Procedure và truyền tham số.
3. Logic kiểm tra mã đơn hàng, mã hàng, trạng thái scan phải nằm trong SQL Server.
4. Không cập nhật dữ liệu trực tiếp vào bảng ERP.
5. Mã đơn hàng phải được lưu vào bảng mapping của WMS.
6. Nên xử lý mã đơn hàng ở cấp dòng chi tiết phiếu nhập.
7. Khi bắt đầu quét nhập, dữ liệu thùng/pallet sinh ra phải kế thừa `MaDonHang`.

Điểm quan trọng: **mã đơn hàng phải được chốt trước khi quét nhập**. Nếu để quét nhập trước rồi mới sửa mã đơn sau, dữ liệu tồn kho và xuất kho sẽ rất dễ lệch. Đây là điểm cần khóa chặt trong thiết kế.
